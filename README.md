# a5e-party-sheets

A read-only, login-gated website where players review their [Level Up: Advanced 5th Edition](https://www.levelupa5e.com/) character sheets between sessions. The GM uploads enriched Foundry VTT actor exports after each session; every upload is an immutable snapshot and the latest one is displayed.

**Status: planning in progress** The build-ready spec and decision records are being assembled and will land here before any application code.
